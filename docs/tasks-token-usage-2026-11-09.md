## Resolved decisions (owner, 2026-11-09)

Every edit pass reads this section as the shared contract. Where a spec disagrees with it, the spec changes.

- **D-1. `model` in the ledger** is the LLM model name, for example `opus`, `sol` or `luna`. It is never the llm-gateway alias (`default`, `deep`). On failover it is the model that answered the attempt (the payload's `model`). For harness runs the launcher supplies the model it resolved from the alias table (models-and-usage Open 23). ADR-0005 gets a dated amendment.
- **D-2. Budgets are gone from the documents.** Remove every note, row, section and non-goal line that mentions budgets, cost, price, money, reservations, admission or pausing on usage, including "Removed (ADR-0005)" tombstones about them. Keep the ADR, `docs/` history (task files, assessments, `decisions-pending`), and the unrelated uses of the words (`grilling` "budget" as a project constraint; "money" as a risky-logic test category). Section numbers in `exception-flows` stay: 6.6 is dropped and 6.7 onward keep their numbers. The machine-shutdown `.pause` / `PAUSE.md` / `machine_paused` is not a budget item and **stays**. ADR-0005's title says "no usage pause" and its "Kept" list names the machine-shutdown pause (closes B7).
- **D-3. Handoff event** is `handoff_request` with payload `{ session_id, task_id, reason, context_used, context_limit, packet }`. `reason` is `context_graceful` or `context_emergency`. `handoff_initiated` is dropped. `agent-execution` uses these field names, not `token_usage` / `token_limit`. `escalate` / `session_escalated` is not part of this change.
- **D-4. `compression_level`** is removed from agent-session, context-persistence and models-and-usage (and models-and-usage Open 22).
- **B2.** The harness total is `input + output`, cached tokens excluded, as in llm-gateway line 161. The launcher supplies `model`.
- **B3.** (default taken) llm-gateway section 3.1 defines `Usage.input_tokens` as uncached input, with `cached_input_tokens` and `cache_write_tokens` separate. `context_tokens` of a step = `input_tokens + cached_input_tokens + cache_write_tokens + output_tokens` of that step's last call (not cumulative). The ledger `tokens` stays `input + output`. CLI Workers have no `context_tokens`; the 90 % rule does not apply to them.
- **B4.** One key, `context_windows.<alias>`, in `umas.config.yaml`, no default. A missing value for a used alias is a `ConfigError` at start-up. Orchestration and context-persistence read it. Fallback alias uses the smaller window (Open 17).
- **B5.** The daemon calls `ingest_token_ledger` every `ingest.interval_seconds` (300). `ingest.token_ledger` is the same path as `token_ledger.ledger_path`. Closes metrics-store Open 1.
- **M1** the Monitor escalates; the Coordinator sends the emergency handoff. **M2** the session row carries `context_tokens` and `context_limit`; CLI Workers have none. **M3** SessionConfig row adds `counter` and `event_source`; `handoff()` calls `pack()`. **M4** one absolute `token_ledger.ledger_path` in `umas.config.yaml`. **M5** `umas metrics tokens` defaults to all time. **M6** the ledger is kept forever; the metrics window is stated. **M7** the gateway catches, logs and ignores `on_usage` exceptions. **M8** add `LedgerWriteFailed`. **M9** (simplified: no budget) state that a crash between a Worker run and `record` can lose that run's line; no atomic store. **M10** a failed handoff falls back to the last `STATE.md` checkpoint, flagged degraded, and raises P2.
- **Minors m1, m3 to m13 and m15** follow the report text. m2 is closed by D-4. m14 (`admit` in task-queue) is out of scope, except that the one line naming the removed budget check is removed under D-2.
